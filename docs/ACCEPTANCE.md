# 인수 기준 점검 · 2026-09-20

후속 업데이트: OpenAI 키 연결 후 실제 API 호출은 사용 한도/결제 관련 HTTP 429로 거절되었습니다. 아래는 최초 MVP 점검 기록이며 최신 연결 결과는 [live 검증 보고서](LIVE_VERIFICATION.md)에 있습니다.

`codex_handoff/07_ACCEPTANCE_CRITERIA.md`를 기준으로 점검했습니다. **공식 페이지 기반 vertical slice는 실행 검증했고, LLM을 통한 전 경로 탐색 및 실제 확정 가격 데모는 아직 검증하지 못했습니다.** API 키가 없는 환경에서 확인되지 않은 가격을 만들어 성공으로 표시하지 않았습니다.

## 실행 결과

- 저장소의 handoff 문서 9개를 구현 전에 모두 읽었습니다. 기존 애플리케이션 코드는 없었습니다.
- UI 구현 전에 `npm run poc`로 실제 에버랜드 공식 출처를 읽어 스키마에 맞는 결과를 얻었습니다.
- 첫 PoC: 약 1.6초, 실제 탐색 3개 범주, 후보 5개, `needs_info` 5개, `confirmed` 0개. 정가·내 가격은 null입니다. 가격·기간을 하드코딩하지 않았습니다.
- `npm run typecheck`, `npm run lint`, `npm run build`: 통과.
- 최종 결과: 엔진 테스트 **40/40 통과**, 브라우저/API 시나리오 **5/5 통과**. 브라우저 실행 약 16.5초.
- 엔진 회귀 테스트: 스키마, eligibility 4상태, 만료, 누락, 정확한 카드 상품, arithmetic, 한도, 구매 문맥, 근거 위조, 출처 충돌, 병렬 제한, 실패 격리 등을 검증합니다.
- headless Edge 브라우저: 1440px PC 및 390px 모바일, 실제 공식 검색·프로필 저장·필터·방문일·drawer·출처 링크·가로 넘침·API 입력 오류·시간 초과 화면을 검증합니다.

## Failure states

| 상황                      | 처리                                                                                       |
| ------------------------- | ------------------------------------------------------------------------------------------ |
| 검색 결과 없음            | 빈 결과 설명, 할인 자체가 없다고 단정하지 않음                                             |
| 일부 웹 탐색 실패         | 해당 task만 failed, 나머지 유지, 경고 표시. 단위 테스트                                    |
| LLM malformed output      | Zod 오류가 task 수준에선 격리, 의도/계획 수준에선 안전한 502. 합성 malformed output 테스트 |
| 정가 미확인               | null, 미확인 이유 및 계산 보류. 라이브 검증                                                |
| 혜택은 있지만 조건 미확인 | needs_info 또는 unknown. 라이브 검증                                                       |
| 출처 충돌                 | confidence low, 계산 차단, caveat. 단위 테스트                                             |
| 시간 초과                 | fetch/SDK/전체 deadline, 경로 격리, UI 재시도. 브라우저 오류 응답 주입 테스트              |

## 아직 완료했다고 볼 수 없는 항목

1. **실제 LLM E2E**: API 키가 없어 호출하지 못했습니다. 자연어·검색 계획·추출 어댑터를 구현하고 SDK 스키마 변환을 테스트했지만, 실호출 성공을 주장하지 않습니다.
2. **실제 확정 할인 + 내 가격 시연**: 현재 직접 탐색 모드에서는 이미지/동적 페이지 때문에 전체 조건과 정가가 불명확합니다. 라이브 데모는 검증 가능한 후보·추가 확인 정보·공식 출처까지이며, 실제 confirmed/최저가를 보여주는 단계는 남아 있습니다. 가격 계산 성공은 합성 단위 테스트에서만 확인했습니다.
3. **통신사·멤버십·연령·지역 실탐색**: 직접 탐색 모드에서는 미지원으로 명시합니다. 웹 검색 모드의 실호출 검증과 제공자 확장이 필요합니다.
4. **서로 다른 공식 제공자 간 교차 검증**: 현재 라이브 검증은 에버랜드 한 제공자의 여러 상세 페이지입니다. 다중 제공자의 일치 여부는 검증하지 못했습니다.

우선순위는 OpenAI 키 연결과 실제 평가 → 날짜/연령별 공식 정가·기간 수집 → 필드별 근거/조건 누락 검증 → 다른 제공자 확대입니다.
